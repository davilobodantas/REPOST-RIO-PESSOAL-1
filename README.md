# Portfólio Pessoal: Protótipo no Figma

Entregável da Semana 03 da disciplina de Design de Experiência e Prototipação.

## 1. Descrição do projeto

Este repositório documenta o protótipo de um portfólio pessoal desenvolvido no Figma. O objetivo do projeto é apresentar, de forma clara e organizada, a trajetória, as habilidades técnicas e os projetos de um desenvolvedor Python júnior, simulando a experiência de navegação de um portfólio profissional real.

## 3. Estrutura do portfólio

O protótipo é composto por duas telas principais, desenvolvidas para desktop (1440 px).

**Tela 1: Página inicial (Home)**

| Seção | Finalidade |
|---|---|
| Navegação | Acesso rápido às seções Sobre, Skills, Projetos e Contato |
| Apresentação | Identificação do autor, cargo pretendido e chamadas para ação (Ver projetos e Baixar CV) |
| Sobre mim | Trajetória, interesses e objetivos profissionais |
| Stacks e habilidades | Tecnologias organizadas em três níveis: uso diário, em desenvolvimento e em aprendizado |
| Projetos | Grade com três cartões de projeto, contendo imagem, descrição breve, tecnologias e botão "Ver detalhes" |
| Contato | Links para GitHub, LinkedIn e e-mail |

**Tela 2: Página individual do projeto**

Acessada por meio do botão "Ver detalhes" de cada cartão. Contém visão geral, tecnologias utilizadas, funcionalidades, desafios e aprendizados, links do repositório e botão "Voltar" para a página inicial.

## 4. Fluxo de navegação (protótipo interativo)

1. O usuário acessa a página inicial.
2. Ao selecionar "Ver detalhes" em um projeto, é direcionado à página individual correspondente.
3. Ao selecionar "Voltar", retorna à página inicial.
